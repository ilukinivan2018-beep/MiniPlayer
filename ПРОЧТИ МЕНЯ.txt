МИНИ-ПЛЕЕР ДЛЯ ЭКРАНА ТЕЛЕФОНА
==============================

Превращает старый телефон на Android во второй сенсорный экран для компьютера:
  1. Плеер — обложка, название, перемотка, громкость. Работает с Яндекс Музыкой,
     Spotify, музыкой в браузере (ВК, YouTube) и почти любым проигрывателем.
     Внизу визуализатор, который прыгает под настоящий звук.
  2. Текст песни — подсвечивается в такт музыке (тексты из бесплатной базы LRCLIB).
     Тап по строчке — перемотка на неё.
  3. Монитор системы — видеокарта (NVIDIA), видеопамять, температура, процессор,
     оперативка, сеть, графики за 2 минуты.
  4. Пульт — плитки: запуск программ, «свернуть всё», скриншот, микрофон и т.д.

Страницы листаются свайпом влево-вправо.

Что нужно: Windows 10 или 11, телефон или планшет на Android, USB-кабель.
Python установщик найдёт сам (или предложит поставить).


ШАГ 1. ТЕЛЕФОН КАК ВТОРОЙ МОНИТОР (spacedesk, бесплатно для личного использования)
--------------------------------------------------------------------------------
1) На компьютер: скачай «spacedesk DRIVER» с официального сайта https://www.spacedesk.net/
   и установи. Если спросит про перезагрузку — можно позже.
2) На телефон: установи «spacedesk Viewer» из Google Play.
3) Подключение по кабелю (быстрее и без задержек):
   - на компьютере открой spacedesk Console (значок возле часов)
     → слева Communication Interfaces → USB Cable Driver Android
     → поставь галочку «USB Cable Android»;
   - подключи телефон кабелем, в уведомлении USB выбери «Передача файлов»;
   - открой spacedesk Viewer — компьютер появится в списке, нажми на него.
   Подключение по Wi-Fi тоже работает, но для него надо сделать сеть «Частной»
   в настройках Windows и разрешить spacedesk в брандмауэре.
4) На компьютере: Параметры → Система → Дисплей → «Расширить эти экраны».
   Там же можно поставить телефону масштаб 150–200%, если всё мелкое.


ШАГ 2. УСТАНОВКА МИНИ-ПЛЕЕРА
----------------------------
1) Распакуй архив в обычную папку, например C:\MiniPlayer
   (не запускай прямо из архива!).
2) Запусти install.bat и дождись надписи «Готово!» (1–3 минуты).
3) На рабочем столе появится ярлык «Мини-плеер» с синей нотой — запускай его.
   Плеер сам откроется во весь экран на телефоне.

Если Windows покажет «Windows защитила ваш компьютер» — нажми «Подробнее» →
«Выполнить в любом случае» (так бывает со всеми неподписанными программами).


УПРАВЛЕНИЕ
----------
Свайп влево/вправо или клавиши 1–4 ... переключение страниц
← / →  (в окне плеера) ............... предыдущий / следующий трек
↑ / ↓  (в окне плеера) ............... громкость
Пробел ................................ пауза
Ctrl + Alt + стрелки .................. то же самое из ЛЮБОЙ программы
Двойной тап по пустому месту .......... полный экран вкл/выкл
Alt + F4 (курсор на экране телефона) .. закрыть плеер

Защита экрана телефона от выгорания включена сама: картинка незаметно
сдвигается, кнопки притухают, без музыки экран затемняется. Первый тап
по тёмному экрану только будит его.


НАСТРОЙКА ПУЛЬТА
----------------
Плитки хранятся в файле deck.json (появится после первого запуска).
Его можно открыть Блокнотом и поменять. Типы действий:
  {"type": "run",  "path": "C:\\путь\\к\\программе.exe"}   — запустить программу
  {"type": "url",  "url": "https://..."}                   — открыть сайт
  {"type": "keys", "keys": "ctrl+shift+esc"}               — нажать сочетание клавиш
  {"type": "minimize"}, {"type": "mic"}, {"type": "mute"}, {"type": "lock"}
После правки просто перелистни на пульт — он перечитает файл.


РАСШИРЕНИЕ ДЛЯ БРАУЗЕРА: ВИДЕО НА ВТОРОЙ ЭКРАН
---------------------------------------------
Правый клик по видео → «Вывести видео на второй экран» — вкладка с видео
переезжает на телефон во весь экран (без перезагрузки). Esc — обратно.
Работает в Chrome, Edge и Яндекс Браузере.

Установка (один раз):
1) Открой в браузере chrome://extensions (в Edge — edge://extensions).
2) Включи «Режим разработчика».
3) «Загрузить распакованное расширение» → выбери папку extension
   из папки мини-плеера.
4) Закрепи значок расширения (значок пазла рядом с адресной строкой).

Как пользоваться:
- Туда: правый клик по видео (на YouTube — правый клик два раза),
  значок расширения или Alt + Shift + V.
- Обратно: Esc, кнопка «Вернуть в браузер» на телефоне или
  кнопка на вкладке-заглушке.
- Стрелки: ← / → — видео, ↑ / ↓ — громкость Windows (как в плеере).


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
- Плеер не открылся на телефоне — проверь, что телефон подключён как второй
  монитор (шаг 1), и запусти ярлык ещё раз.
- Монитор пишет «видеокарта не найдена» — данные о видеокарте сейчас умеет
  показывать только для NVIDIA, остальное работает.
- Журналы ошибок лежат в папке logs.


Используемые библиотеки (все со свободными лицензиями MIT/BSD): pywinrt, pycaw,
comtypes, psutil, nvidia-ml-py, numpy, SoundCard. Тексты песен — из LRCLIB
(lrclib.net), права на тексты принадлежат их авторам.
